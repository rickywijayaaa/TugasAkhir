## 4. Interpretasi Hasil

### Temuan Utama

**QR konsisten lebih buruk dari Baseline di semua metrik, pada 500 sampel.**

1. **Label `no` paling terdampak:**
   - Accuracy −4.4pp, Faithfulness −0.046, Context Recall −0.060
   - QR cenderung reformulasi query ke arah afirmatif → dokumen negatif tidak ter-retrieve → LLM prediksi `yes`

2. **Paradoks retrieval score:**
   - BM25 score QR lebih tinggi (+5.48 = +21.7%) tapi semua metrik kualitas turun
   - Query yang lebih panjang/verbose menaikkan BM25 score secara artefak, bukan karena dokumen lebih relevan

3. **Satu-satunya keuntungan QR: label `maybe` faithfulness (+0.020)**
   - Minor (hanya 66 sampel) — QR sedikit membantu pada pertanyaan ambigu/kontradiktif
   - Namun context recall `maybe` tetap turun (−0.010)

4. **Semantic drift terkonfirmasi:**
   - Context Recall turun di semua kelas meski BM25 score naik → dokumen yang diambil tidak mencakup informasi yang seharusnya ada di reference

### Hipotesis Penyebab Degradasi QR

| Faktor | Penjelasan |
|--------|-----------|
| Semantic drift | LLM mereformulasi 100% query, mengubah framing dari evaluatif ke deskriptif |
| BM25 incompatibility | Query verbose → keyword penting terdilusi dalam scoring |
| Afirmation bias | Query hasil rewriting condong positif → miss dokumen negatif |
