## 1. Perubahan Evaluasi RAGAS: Dari RAGAS ke Custom Zero-NaN

### Masalah RAGAS dengan LLM Lokal

Setelah investigasi pada sesi ini, ditemukan 3 penyebab NaN berbeda:

| Metrik | NaN Rate | Penyebab |
|--------|----------|---------|
| Context Precision | 89% | 5 LLM calls/sampel × JSON `{"verdict": 1}` → satu gagal = NaN semua |
| Answer Relevancy | 72% | `OutputParserException` — llama3.2 tambah teks sebelum JSON |
| Faithfulness | 63% | "No statements generated" — LLM gagal parse list of claims |
| Context Recall | 8% | Paling reliable, berbasis reference teks terstruktur |

**Kunci:** NaN tidak berkorelasi dengan panjang/kualitas jawaban (NaN avg 471 chars vs valid 497 chars) — murni masalah infrastruktur RAGAS + local LLM.

### Solusi: Custom Zero-NaN Evaluator

Bypass RAGAS chain sepenuhnya. Tidak ada JSON parsing, hanya yes/no sederhana:

```python
# Faithfulness
sentences = re.split(r'(?<=[.!?])\s+', answer)    # deterministik, tidak bisa gagal
for sent in sentences:
    "Is this statement supported by context? yes/no"  # prompt minimal
score = supported / len(sentences)                    # selalu 0.0–1.0

# Context Recall — pola identik, tapi cek reference vs contexts
```

**Hasil:** NaN = 0 di kedua konfigurasi (100 sampel).

File output: `baseline_phase2_custom.json`, `qr_phase2_custom.json`

## 4. Interpretasi Hasil

### Temuan Utama

**QR lebih buruk dari Baseline di semua metrik utama.** Penurunan paling signifikan:

1. **`no` accuracy turun −11.5% (100s) / −4.4% (500s):** QR mereformulasi query sehingga konteks yang diambil lebih condong mendukung hipotesis → LLM prediksi `yes` padahal ground truth `no`.

2. **Context Recall `no` turun −10.6%:** Konfirmasi bahwa dokumen relevan untuk menjawab `no` tidak berhasil diambil setelah rewriting.

3. **Paradoks retrieval score:** QR menaikkan BM25 score (+5.48 = +21.7%), tapi menurunkan semua metrik kualitas. Query lebih panjang → BM25 score naik secara artefak, bukan karena dokumen lebih relevan.

4. **`maybe` faithfulness QR lebih tinggi (+0.047):** Satu-satunya sinyal positif QR — jawaban ambigu lebih grounded ke konteks setelah rewriting.

### Hipotesis Penyebab Degradasi QR

- **Semantic drift:** LLM mengubah query terlalu agresif (100% query berubah) → mismatch antara dokumen yang diretrieval dan pertanyaan asli yang digunakan untuk generate
- **BM25 tidak cocok untuk QR:** Query verbose → keyword penting terdilusi di BM25 scoring
- **Generation tidak memanfaatkan konteks lebih baik:** Meski retrieval score naik, LLM tidak menghasilkan jawaban yang lebih akurat
